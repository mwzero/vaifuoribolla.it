# 📱 vai fuori bolla .it - Repository Ufficiale

Benvenuto nel repository di gestione di **vaifuoribolla.it**. Questo sito funziona come un archivio statico indipendente.

## 🛠️ Come pubblicare un nuovo articolo

1. Entra nella cartella `content/blog/`.
2. Crea un nuovo file con estensione `.md` seguendo la nomenclatura: `AAAA-MM-GG-titolo-post.md`.
3. Copia l'intestazione standard (Frontmatter) compilando titolo, data e categoria.
4. Ricorda di strutturare sempre l'articolo inserendo la tabella di confronto diretto `| Il Reel Dice | La Realtà dei Fatti |`.

## 🎨 Linee Guida per i Redattori
*   **Neutralità assoluta:** Non attacchiamo le persone, smontiamo i frame retorici attraverso i numeri.
*   **Fonti obbligatorie:** Ogni dato inserito deve avere un link ipertestuale diretto a istituti ufficiali (INAIL, ISTAT, Ministeri, OCSE, Banca d'Italia).
